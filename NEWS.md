# Updates's info

## Version 1.0.7

*26-12-2025*

* [UI_Creator_FromCSV] Добавлены параметры `CfgName`, `CuixName` со значениями по умолчанию `NC_UI_DEF`;

## Version 1.0.6

*09-04-2025*

* CFG-файл теперь сохраняется в кодировке `UTF8-BOM` из-за наличия в противном случае в nanoCAD в некоторых случаях "кракозяб";
* При использовании ресурсных DLL (IconResourceVariant.ResDll) в CFG файл записывалось имя DLL без расширения, это приводило к падению nanoCAD при попытке запуска;

## Version 1.0.5

*10-10-2024*

* Удалены форматы иконок MediumWithText и MediumWithoutText (они не применяются в nanoCAD), под Medium понимается LargeWithoutText в 2 ряда;
* [UI_Creator_FromCSV] Исправление логики чтения файла (имя команды (CommandMethod) и заголовок команды читались неверно);
* [UI_Creator_FromCSV] В конфиг добавлена настройка `PlaceLargeWithoutTextIconsEconomy` позволяющая не размещать иконки со стилем `LargeWithoutText` в 2 ряда (по умолчанию так делается);

## Version 1.0.4

*30-09-2024*

* [UI_Creator_FromCSV] Если табличный файл, указанный в конфиге не найден, то идет попытка найти его в одном каталоге с конфиг-файлом, если и это не удается, то выбрасывается стандартное исключение FileNotFoundException;

## Version 1.0.3

*30-09-2024*

* [UI_Creator_FromCSV] Настройка `DeleteTempFiles` переименована на `DeleteCUIXFiles` с сохранением логики работы; 
* [UI_Creator_FromCSV] Добавлена опция `DeleteConfigFiles `, позволяющая удалить конфиг файл и табличный файл;
* Исправлена ошибка сохранения CUIX файла в папке с исполняемой библиотекой, в то время как CFG сохранялся куда-надо (сценарий авто-генерации UI по файлу);

## Version 1.0.2

*30-09-2024*

* [UI_Creator_FromCSV] Добавление опции `DeleteTempFiles`, позволяющая удалять составные части файла CUIX после его создания;

## Version 1.0.1

*29-09-2024*

* Функциональность по созданию UI на основе CSV вынесена в отдельный консольный проект, который принимает на вход XML-конфиг. Переделан пример и описание репозитория для нового подхода;
